Essa atividade/projeto tinha o objetivo de corresponder a seguinte instrução: Crie um programa em linguagem C que utilize uma struct para armazenar dados de um livro. A struct deve conter os seguintes campos:

título (string) autor (string) ano de publicação (inteiro)

O programa deve:

Ler os dados de um livro informados pelo usuário; Exibir as informações do livro na tela.

Com base nessas instruções foi desenvolvido tal algoritmo simples que pegava dados de um cadastro fictício de livro e colocava suas informações(atribuições) dentro de uma Struct chamada livro e mostrava os dados registrados na interação com o programa.
